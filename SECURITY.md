# Security Policy / Sicherheitsrichtlinie

## Supported Versions / Unterstützte Versionen

Only the latest release receives security and compatibility fixes.
Es werden nur für das neueste Release Sicherheits- und Kompatibilitäts-Fixes bereitgestellt.

| Version | Supported / Unterstützt |
|---|---|
| Latest release / Neuestes Release | ✅ |
| Older releases / Ältere Releases | ❌ |

## Reporting a Vulnerability / Sicherheitslücke melden

**English**

Please do **not** open a public issue for security-sensitive problems.
Report them privately through the Discord modding server:

- Discord: https://discord.gg/cRS4bCKUbe

Please include:

- what you found
- how to reproduce it
- the Data Center version
- the MelonLoader version
- the version of this tool

You will usually receive a first response within a few days.

**Deutsch**

Bitte **kein** öffentliches Issue für sicherheitsrelevante Probleme erstellen.
Melde sie vertraulich über den Discord-Modding-Server:

- Discord: https://discord.gg/cRS4bCKUbe

Bitte gib an:

- was du gefunden hast
- wie es reproduzierbar ist
- die Data-Center-Version
- die MelonLoader-Version
- die Version dieses Tools

In der Regel gibt es innerhalb weniger Tage eine erste Rückmeldung.

## Scope / Geltungsbereich

This is a community-maintained debugging and modding tool, intended for local
use with your own copy of the game. Do not use runtime inspection or modding
tools in environments where they are not allowed.

Dies ist ein community-gepflegtes Debugging- und Modding-Tool, gedacht für die
lokale Nutzung mit der eigenen Spielkopie. Verwende Runtime-Inspektions- oder
Modding-Tools nicht in Umgebungen, in denen sie nicht erlaubt sind.
